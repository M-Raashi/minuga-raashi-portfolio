# Minuga Raashi - Personal Portfolio

This portfolio is created for the Full Stack Development Assignment-1.

## Sections
- Home
- About
- Education
- Skills
- Internship
- Projects
- Certifications
- Contact

## Technologies
- HTML5
- CSS3
- Bootstrap 5
- JavaScript (ES6+)
- Bootstrap Icons

## JavaScript Features
1. Dark/light theme switching
2. Project filtering
3. Client-side contact form validation
4. Active navigation highlighting
5. Dynamic copyright year

## Run in VS Code
1. Extract this folder.
2. Open the folder in VS Code.
3. Open `index.html`.
4. Install the Live Server extension if needed.
5. Right-click `index.html` and choose **Open with Live Server**.
